How the pipeline works
1

Train

XGBoost on 284K transactions (577:1 imbalance, handled via scale_pos_weight). PR-AUC is the primary metric — not ROC-AUC.

2

Register

MLflow tracks experiments, stores artifacts in S3, and promotes the best model to @champion alias.

3

Serve

FastAPI with typed request schemas. Every prediction emits Prometheus counters and histograms.

4

Monitor

Prometheus scrapes request rate, fraud rate, and confidence distributions. Grafana dashboards visualize trends.

5

Detect drift

Evidently batch job compares live predictions against a reference distribution. Drift metrics go to Pushgateway.

6

Alert

Grafana fires alerts when fraud rate spikes above 3× baseline or more than half of features drift simultaneously.
